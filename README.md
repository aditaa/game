# Padda Ripples

A browser-based click-gathering game. Collect glowing Paddas, build a combo, and use their abilities before the 30-second round ends.

## Play

Visit <https://aditaa.github.io/game/>.

Click Paddas with a mouse or touchscreen. For keyboard play, focus the game canvas and press <kbd>Space</kbd> or <kbd>Enter</kbd>.

The game is static HTML, CSS, and JavaScript with no build step or external dependencies.
